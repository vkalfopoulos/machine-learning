Overview

This project develops a pipeline for detecting question similarity in knowledge-based platforms like Quora, a key challenge in natural language processing (NLP). By combining classic NLP preprocessing techniques with manually engineered features, we identify degrees of question similarity using a Random Forest Classifier. The approach provides a reliable baseline for question pair matching, with potential applications in data curation and user engagement.

Dataset

The project uses a dataset of question pairs, typically sourced from platforms like Quora or Kaggle's Quora Question Pairs dataset (not explicitly specified in the provided text, but implied for such tasks). The dataset includes:

Pairs of questions in text format.

Binary labels indicating whether the questions are duplicates (similar) or non-duplicates.

Features like question text, character length, and word counts.
