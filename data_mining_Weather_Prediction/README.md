
# Data Mining Weather Prediction

Overview
This project applies data mining techniques to predict weather patterns,
focusing on improving forecast accuracy for applications like agriculture, disaster management, and resource planning.
By analyzing historical and real-time meteorological data, 
we leverage machine learning algorithms to uncover patterns and relationships for reliable weather predictions.

Datasets
The project utilizes meteorological data from the following sources:
National Oceanic and Atmospheric Administration (NOAA): Provides temperature, pressure, humidity, wind speed, precipitation, and solar radiation data.


European Centre for Medium-Range Weather Forecasts (ECMWF): Supplies high-resolution weather and climate model outputs.

Indian Meteorological Department (IMD): Offers regional weather data, including rainfall and temperature records.
Other Sources: Satellite imagery, radar systems, ground weather stations, and weather balloons for real-time and historical data.


Data includes measurements like temperature, atmospheric pressure, humidity,
wind speed, precipitation, and solar radiation, collected in real-time and as historical records.
